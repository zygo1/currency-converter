# currency-converter

A small currency converter built with React, TypeScript and styled-components, bundled with Webpack. Rates come from Frankfurter, which fetches data from central banks.

## Running it

```bash
npm install
npm start          # port 3000
npm run build      
```

## Stack

- React 19 + TypeScript
- styled-components for styling and theming
- Webpack 5, configured from scratch (Babel, HtmlWebpackPlugin, fork-ts-checker for parallel typechecking)
